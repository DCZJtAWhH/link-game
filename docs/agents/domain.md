# 领域文档

本仓库采用单上下文布局：

- GLOSSARY.md：仓库根目录的领域术语表。
- docs/adr/：架构决策记录目录。

## 探索代码前

读取根目录 GLOSSARY.md，以及 docs/adr/ 中与当前工作相关的决策。

文档尚不存在时直接继续；不因缺少文档而中断或主动建议补建。
domain-modeling 技能在实际明确术语或决策时按需创建这些文档。

## 使用统一术语

在任务标题、设计建议、假设和测试名称中，
使用 GLOSSARY.md 定义的领域术语，遵循其中约定的命名。

需要的概念尚未收录时，先判断是否引入了项目不使用的概念；
确有术语缺口时，记录为后续 domain-modeling 的输入。

## 显式说明决策冲突

方案与现有 ADR 冲突时，明确指出对应 ADR、冲突内容和重新讨论的理由。
