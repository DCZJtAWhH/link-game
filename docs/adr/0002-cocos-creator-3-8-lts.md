# 使用 Cocos Creator 3.8 LTS，共用浏览器和微信玩法逻辑

用户确认将水果连连看切换到 Cocos Creator 3.8 LTS，基础环境固定为 3.8.8，由 Creator 管理 2D 场景、界面、资源和浏览器／微信小游戏构建。该决策取代 ADR 0001 的原生 Canvas 2D 绘制与手工平台打包方案，以获得可视化编辑及引擎提供的微信平台适配，接受编辑器安装、场景资源维护和构建对编辑器的依赖。

玩法逻辑继续使用不依赖 `cc`、DOM 或 `wx` 的 TypeScript 模块，并通过 Vitest 检查；pnpm 管理工程辅助依赖。引擎组件负责显示和输入，平台能力经引擎或独立适配接入。本次只搭建最小工程，不扩展已确认的玩法范围，也不将微信产物构建等同于微信运行验收。
